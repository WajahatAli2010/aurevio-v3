# Aurevio v3

A modern portfolio website for an independent web developer, rebuilt with a faster and more accessible front-end stack.

## Features
- Vite-powered development and production build
- Static, pre-rendered sections for fast load times
- Responsive layout with dark/light theme toggle
- Stronger semantic structure and keyboard-friendly navigation
- Reusable CSS variables and modular design system
- Structured data and SEO metadata

## Local development

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Project structure

```text
index.html
src/
  main.js
  styles.css
public/
  favicon.svg
  robots.txt
  sitemap.xml
```

## Notes
The design follows the original Aurevio identity while improving performance, accessibility, and scalability.
